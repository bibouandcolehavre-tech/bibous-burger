Installer Krokli Driver sur mon téléphone

Retrouve tes courses depuis une icône sur ton écran d’accueil.

iPhone et iPad · Safari

  1. Ouvre cette page dans Safari, puis le menu Partager (carré avec une flèche vers le haut).
  2. Choisis Sur l’écran d’accueil. Si l’option apparaît, active Ouvrir comme app web, puis touche Ajouter.
  3. Ouvre l’icône Krokli Driver et connecte-toi avec ton compte livreur.

Android · Chrome

  1. Ouvre cette page dans Chrome.
  2. Utilise le bouton d’installation lorsqu’il apparaît, ou le menu ⋮ : Installer et créer un raccourci, puis Installer. Selon la version, l’option s’appelle Ajouter à l’écran d’accueil.
  3. Ouvre l’icône Krokli Driver et connecte-toi avec ton compte livreur.

Dans le navigateur d’une messagerie, ouvre d’abord le lien dans Safari ou Chrome. Une connexion Internet est nécessaire pour voir les courses et confirmer chaque étape. L’installation peut demander une nouvelle connexion à ton compte.

Partage volontaire · jusqu’à ton arrêt

Partager ma position avec Bibou

Pas de coupure après 30 minutes : utilise « Arrêter le partage GPS » quand tu as terminé. Sur cette version web, garde cette page au premier plan : le suivi peut être suspendu avec Plans ouvert ou le téléphone verrouillé. Fermer la page ou te déconnecter arrête le partage. Aucun historique des trajets n’est conservé.

Seule l’équipe connectée du restaurant voit ta dernière position reçue ; les clients ne la voient pas. Elle disparaît au plus tard après 90 secondes sans réception. Cet essai ne bloque aucune étape de livraison.

Guidage GPS · voiture

Mon application GPS

Ouvrir le GPS

Ton GPS s’ouvre avec la destination : il assure la voix et le recalcul. Vérifie l’adresse, puis touche « Démarrer » ou « Aller » si demandé.

Suivi Bibou sur la version web : le navigateur peut suspendre le partage de position quand tu ouvres le GPS ou verrouilles le téléphone. Reviens dans Krokli pour confirmer la livraison.

Fonctionnement et confidentialité

Sans l’application GPS installée, le lien peut ouvrir une page web. Waze peut demander de choisir l’adresse. Seule cette destination est transmise : aucun nom, téléphone, identifiant de commande ou accès Bibou n’est ajouté au lien. Fais les réglages à l’arrêt.
